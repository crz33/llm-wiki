# Query

`vault/20_wiki/` の内容をもとに質問に答える。このスキルは **読み取り専用** であり、`vault/20_wiki/` `vault/10_raws/` `vault/00_pools/` など、いかなるファイルへの書き込みも行わない (`log.md` にも記録しない)。回答の記録は `/session` の担当であり、このスキルの範囲外。

呼び出し時の引数(ARGUMENTS)を質問文として扱う。引数がない場合は、何を知りたいかをユーザに確認する。

## 手順

1. `vault/20_wiki/index.md` を読み、関連しそうなページの当たりをつける
2. 該当ページ(`entities/` `concepts/` `sources/`)を読み、出典を `[[ページ名]]` の形式で明記した上で回答する
3. `index.md` を見ても関連ページが見つからない場合は、無理に回答をひねり出さず、該当する情報が Wiki にない旨を正直に伝える

## 注意

- 複数ページにまたがる質問の場合も、根拠になったページはすべて `[[ページ名]]` で示す
- 推測や一般知識で補う場合は、Wiki の記述とは別物だと分かるように明示する
